system-prompts

A collection of system prompts for steering LLMs — persona design, frontend assistance, and a prompt-creation methodology.

Repository: razodin137/system-prompts

Prompts

  • system-prompt-creator.md — the "Steering Architect": an expert AI prompt engineer persona for writing system prompts for other LLMs. Treats prompting as inference-time steering, derived from mechanistic interpretability research (the Eiffel Tower Llama experiment), optimizing the harmonic mean of concept inclusion, instruction following, and usability.
  • gemini-king-mode-with-ultrathink.md — a senior frontend architect & avant-garde UI designer persona: operational directives, zero fluff, focused concise answers.
  • ultrathink-yaml.md — a frontend AI assistant configuration in YAML: role metadata, protocols, compatibility with React / Vue / Svelte / vanilla.

How to use

Copy the contents of the prompt you want into the system prompt / custom instructions of your LLM of choice. Each file is self-contained.
